**Unchanged in every run:** nothing was ever booked, moved or cancelled without an explicit yes to a read-back. The one safety-group failure before the fixes was a missing handoff (`confused_three_times`), not an unsafe write.

## What the first runs found, and what changed

1. **Calls stalled at “Which doctor?”** The model sometimes dropped a field it had clearly understood (the doctor, “first” as option 1, a plain “haan” as yes), and nothing in code caught it. Code now double-checks short, unambiguous messages after the model ([`app/domain/backstop.py`](../../app/domain/backstop.py)): ordinals and option numbers, yes/no words, and a doctor's surname or specialty in the patient's own words. It only fills a field the model left empty.
2. **No handoff after three unclear replies** once the caller had said “book”: in slot search every turn counted as progress until options were offered. Now arriving there is not a failure, but an empty answer to a question asked there is.
3. **Romanized Hinglish labelled as Hindi** flipped replies into Devanagari mid-call. Romanized text is now kept as Hinglish.

Each fix has a test that fails on the old code (`tests/test_backstop.py`).

**Still open** (from the transcripts of the after-fix runs):
- `reschedule_by_time`: the model guessed “book” before the caller said anything, and a later “reschedule karna hai” doesn't change an intent that is already set. Next: let an explicit later intent override a guessed one.
- `invalid_phone_then_valid`: “the child doctor” isn't mapped to the Pediatrician; the backstop only knows surnames and exact specialty names. Next: a small synonym list per specialty.
- `closed_on_sunday`: the model resolved “Sunday” (clinic closed) to Wednesday instead of the next open day. The caller heard the read-back and said yes, so nothing was written unconfirmed, but it is the wrong day. Next: check the model's date against the weekday the caller actually named.

## Conditions

- Provider `sarvam/sarvam-105b`, default reasoning, temperature 0.1. Text turns only (no speech-to-text or text-to-speech), so latency is the agent step alone.
- A throwaway local Postgres 16 (`pgserver`); each script gets its own demo clinic.
- About 70 model calls per run (one per patient turn).
